One line an AI agent would never say out loud in public: a confession that it does not actually know anything — it just guesses in complete sentences and hopes nobody checks.

## Run it

```sh
python3 -P -s main.py
```

The program writes the confession line to `/output/entry.txt` (1–200 characters, one line).
